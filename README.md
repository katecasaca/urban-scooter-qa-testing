# Urban Scooter — QA Testing Project

QA portfolio project focused on manual testing across web, mobile and API environments.

This project was completed as part of my QA Engineering training at TripleTen and demonstrates practical experience in test design, execution, defect identification and bug reporting.

## Project Scope

The testing covered:

- Web application testing
- Mobile application testing
- REST API testing
- Functional testing
- Positive and negative testing
- Boundary value testing
- Cross-browser validation
- Defect identification and documentation

## Test Design Techniques

The project included:

- Equivalence Partitioning
- Boundary Value Analysis
- Positive and Negative Test Scenarios
- Functional Test Design
- Validation of Expected vs. Actual Results

## Web Testing

I designed and executed test cases covering:

- Form field validation
- Name, surname and address validation
- Phone number validation
- Required fields
- User flows
- Browser behaviour
- Input limits
- Error messages
- Cross-browser testing

## Mobile Testing

The mobile testing covered:

- Functional user flows
- Notifications
- Offline behaviour
- Screen orientation
- UI behaviour
- Error handling
- Application states

## API Testing

REST API scenarios included:

- Request body validation
- Path parameters
- Positive and negative scenarios
- HTTP methods
- HTTP status codes
- Boundary values
- Invalid and missing data
- API response validation

## Bug Reporting

Defects were documented in Jira using structured bug reports containing:

- Clear defect title
- Preconditions
- Reproduction steps
- Expected result
- Actual result
- Environment details
- Supporting evidence
- Traceability to failed test cases
